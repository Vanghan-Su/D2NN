# 方案修改：输入灰度振幅与归一化策略

日期：2026-10-14

## 1. 输入编码

MNIST 图像经双线性插值到 400×400 后，灰度值 \(I(x,y)\in[0,1]\) 作为输入复振幅的模：

\[
U_{\mathrm{in}}(x,y)=I(x,y).
\]

默认对每个样本做 L2 归一化，使每个样本的输入总功率为：

\[
P_{\mathrm{in}}=\sum_{x,y}|I(x,y)|^2=1.
\]

如果显式传入 `--no-normalize-input-amplitude`，则直接使用原始灰度值，并保留每个样本自身的实际输入功率。

## 2. 损失函数

默认归一化模式下，MSE 目标退化为 one-hot：

\[
g_k=\delta_{k,c}.
\]

关闭归一化时，目标使用真实输入功率：

\[
g_k=P_{\mathrm{in}}\delta_{k,c}.
\]

当前代码的完整损失为：

\[
L = \mathrm{CrossEntropy}(s_k,c) + \frac{1}{K}\sum_k\frac{(s_k-g_k)^2}{P_{\mathrm{in}}^2}.
\]

其中 `s_k` 直接作为 10 类 logits，真实类别对应区域的光强积分就是真实类别 logit。

## 3. 汇聚效率

探测器汇聚效率为：

\[
\eta=\frac{\sum_k s_k}{P_{\mathrm{in}}}.
\]

默认归一化模式下 `P_in=1`，关闭归一化时使用每个样本的实际输入功率。

## 4. 代码改动

- `src/d2nn/torch_model.py`：新增 `normalize_input`，默认开启；关闭时保留原始灰度振幅和实际 `P_in`；loss 使用交叉熵加归一化 MSE。
- `src/d2nn/numpy_model.py`：`normalize_input=True` 为默认行为，保留关闭选项。
- `scripts/train.py`：默认启用输入振幅归一化；`--no-normalize-input-amplitude` 可关闭。
- `src/d2nn/training.py`：训练和评价传递逐样本 `input_power`，并记录 `mean_Pin`。
- `tests/`：覆盖归一化、关闭归一化、梯度、损失目标与训练流程。
