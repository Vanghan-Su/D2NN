## 2. 总体判断

方案的核心物理链路是可以实现的：MNIST 振幅输入与第 0 层相位共面，经过 5 次 10 mm 角谱传播和 5 层相位调制，在探测面按 10 个矩形区域积分并分类。

但工程上必须明确以下判断：

1. “全连接”指离散传播核构成稠密、平移不变的线性耦合，并不表示每层有独立的任意权重；可训练量是 5 个 400×400 相位面，共 800,000 个参数。
2. 这是一个“相位-only、传播固定、输入振幅编码”的非凸优化问题，不能只用最终准确率判断实现正确性。必须先验证传播算子、能量、坐标和梯度。
3. 全量训练的风险主要来自数值尺度与算力，而不是模型定义：
   - 2048×2048 的 complex128 单个场为 67.1 MB。
   - 若同时保留 5 个中间场和探测场，单样本约 403 MB；batch=64 仅场张量就约 25.8 GB，尚未计算 FFT 工作区、梯度与优化器状态。
   - 200 epoch、60000 样本、有效 batch=64 对应约 187,600 次参数更新。必须先做显存/耗时基准，不能直接把 batch=64 当作一次 GPU 前向。
4. 建议采用“小尺寸参考实现 → 解析校验 → 前向模型 → 梯度校验 → 规模收敛 → 全量训练”的顺序。推荐首选 PyTorch 2.x 的 `torch.fft` 与 complex128，并保留一个 NumPy 角谱参考实现。

## 3. 必须冻结的仿真约定

| 项目 | 冻结值/约定 |
|---|---|
| 波长 | 632.8 nm |
| 采样 | M=N=400，Δx=Δy=2.5 µm |
| 层尺寸 | 1 mm × 1 mm |
| 层数 | 5 层，索引 0–4，全部可训练 |
| 层位置 | z=0、10、20、30、40 mm |
| 探测面 | z=50 mm，1 mm × 1 mm |
| 传播 | 5 次角谱传播，每次 10 mm |
| 相位 | [0, 2π)，每次优化更新后 wrap |
| 振幅透过率 | 层内 a=1；有限孔径外不施加相位调制 |
| 输入 | MNIST 最近/双线性插值到 400×400，复振幅模为归一化灰度，初相位 0 |
| 输入归一化 | 逐样本归一化，使每个样本的 Pin=1；不要只对全数据集做整体缩放 |
| 探测 | 10 个互不重叠矩形区域，区域光强积分 sk，argmax 分类 |
| 能量 | η=Σsk/Pin，必须与准确率同时报告 |
| 数值 | 传播和优化用 complex128/float64；禁止用 float32 承担约 10^5 rad 的传播相位 |
| 零填充 | 建议 2048×2048；1013 是最小保守下界，不是最终精度证明 |
| 频率 | 使用有符号频率网格，不能用未移位的 0..N-1 直接代替 fx、fy |
| 边界 | 明确采用有限孔径模型；零填充只用于抑制周期回绕，二者不能混用 |
| 探测区坐标 | 原点在探测面左上角，x 向右、y 向下；区域尺寸和中心必须和仿真数组坐标一致 |

角谱传播建议写成归一化形式：

`H(fx,fy)=exp(j·2π·d·sqrt(1/λ²-fx²-fy²))`

当 `1/λ²-fx²-fy² < 0` 时置零。所有传播链路必须在同一扩展网格上完成，最后再取中心 400×400 窗口。

关键数值结果：

- λ·fmax = 0.126560 < 1，400×400 采样带宽内没有倏逝频率。
- 原始 400 网格的相位采样临界距离约为 3.951 mm。
- 10 mm 传播要求 Npad ≥ 1012.5，因此最小值取 1013；实际应做收敛测试后决定 2048 或更大。
- 单像素 10 mm 传播的特征展宽约为 2.531 mm，确实大于 1 mm 层尺寸，因此离散意义上可形成稠密耦合；但这不等价于每层有任意可学权重。

## 4. 工程实施步骤

### P0：冻结规格与接口

任务：

- 把所有常量、单位、索引、坐标和归一化规则写入单一配置。
- 明确 `U_l`、`V_l`、`φ_l` 和传播距离的索引关系。
- 明确探测区域到数字 0–9 的映射和数组行列方向。
- 明确 `sk`、`Pin`、`gk` 是否使用像素面积因子；推荐统一用无量纲归一化强度，避免 loss 尺度混乱。

交付物：

- `configs/base.yaml`
- 一份变量字典和一张系统链路示意图。

验收：

- 任意命名不存在歧义。
- 单样本前向输出尺寸、类别、η 和 loss 都有明确定义。
- 记录所有参数和随机种子。

### P1：建立环境和项目骨架

任务：

- 使用 Python 3.11，安装 NumPy、PyTorch、torchvision、matplotlib、pandas、pytest、tqdm。
- 建立 `src/d2nn/`、`tests/`、`scripts/`、`configs/`、`outputs/`。
- 把物理核、数据、模型、损失、指标、训练入口分离。
- 初始化 Git，固定依赖版本。

验收：

- `pytest` 可运行。
- CPU/目标 GPU 上的最小 FFT 冒烟测试通过。
- 环境、CUDA、硬件和版本信息写入运行记录。

### P2：实现角谱参考核

任务：

- 实现坐标网格、有符号空间频率、倏逝波截断、零填充、传播和中心裁剪。
- 实现有限孔径：只在中心 400×400 区域施加相位，层外保持自由传播。
- 先使用 NumPy 参考实现，不引入可训练参数。

验收：

- 无调制传播的能量守恒相对误差应在 double 精度可接受范围内。
- 高斯光束或已知解析场经一次传播后，光斑位置、尺寸和相位符合预期。
- 单像素脉冲响应不出现环形回绕或半个像素的平移。
- “像素周期复制”和“有限孔径”两种边界模型的结果差异有记录，不能无说明互换。

建议测试：

- 能量守恒测试。
- 高斯光束解析对照测试。
- 单点/单像素响应测试。
- `fftfreq` 频率网格和 `fftshift/ifftshift` 配对测试。
- Npad 改变后的场分布稳定性测试。

### P3：实现前向 D2NN 和探测模型

任务：

- 实现输入上采样、逐样本振幅归一化和 `Pin=1`。
- 实现第 0 层与输入共面：`U0=I`，`V0=U0·exp(jφ0)`。
- 实现 5 层相位调制与 5 次传播。
- 根据探测器区域表生成 400×400 掩模，计算 `sk`、η、预测类别和对比度。

验收：

- 所有张量形状、dtype、设备一致。
- 探测区互不重叠且在 1 mm × 1 mm 范围内。
- 随机/零相位下满足 `η≤1`，数值无 NaN/Inf。
- 固定种子下重复运行结果一致。
- 保存一张输入、各层相位和探测面强度图，坐标方向人工核对。

### P4：梯度和优化原型

任务：

- 先用 PyTorch autograd 建立参考梯度。
- 在小网格（例如 32×32 或 64×64）上用有限差分检查若干随机相位点。
- 再在完整网格上比较 autograd 与手写伴随法/解析梯度的结果。
- 先用 100–1000 个训练样本做过拟合测试，验证 loss 确实可优化。
- 若显存不足，采用梯度累积保持有效 batch=64，并用激活检查点减少中间场占用。

验收：

- 小网格梯度相对误差目标优先设为 1e-6；大网格受 FFT 舍入影响可放宽到 1e-5，但必须解释。
- 过拟合子集上 loss 明显下降，训练子集准确率显著高于随机猜测。
- 没有相位 wrap 后梯度错误、NaN、Inf 或能量异常。
- 手写梯度只在已验证等价后用于大规模训练。

### P5：零填充收敛与资源基准

任务：

- 对固定相位和固定输入，比较 Npad=1013、1536、2048、3072 的探测场、sk、η 和 loss。
- 检查扩展窗口边界附近的能量是否接近零，确认没有周期回绕。
- 比较有限孔径和周期边界的差异，记录最终采用模型。
- 基准测试不同 microbatch、checkpoint、CPU/GPU 下的显存和单步耗时。
- 根据有效 batch=64 决定 micro-batch 和梯度累积步数。

验收：

- Npad 再增大时，关键指标变化低于预设阈值。
- 选定配置在目标硬件上可稳定完成至少一个完整 epoch 的估算。
- 记录“每 epoch 时间、峰值显存、总预计时间、checkpoint 大小”。

### P6：全量训练

任务：

- 使用 Adam、初始学习率 1e-2、有效 batch=64、200 epoch、固定种子。
- 每 epoch 验证，保存最佳 checkpoint、最后 checkpoint、日志和 loss/accuracy 曲线。
- 可增加一条可选分支：复数振幅+相位预训练，再投影到纯相位；投影后必须重新评估，不能把预训练指标当作最终结果。
- 训练前先设定退化条件：若损失不下降、准确率不高于随机基线、η 异常或显存溢出，立即停止并回到 P2–P5。

验收：

- 至少完成一次可复现的训练，测试集结果可重新加载 checkpoint 复现。
- 保存混淆矩阵、η、对比度、相位图和探测面光强图。
- 明确报告首选指标：测试准确率；辅助指标：η、正确区域/次大区域对比度、区域外能量比例。

### P7：评估与敏感性实验

任务：

- 在 10000 张测试集上评估准确率、混淆矩阵、每类召回率和 η。
- 与随机相位、零相位和未训练固定相位基线对比。
- 按需要做有限消融：层数 1/3/5、Npad、层间距、逐样本归一化、纯相位与复数预训练。
- 检查是否存在“探测区尺寸/位置决定结果”而非网络真的完成的退化情况。

验收：

- 所有指标有固定评估脚本和配置文件。
- 结论区分“训练集过拟合”“测试集泛化”和“能量汇聚效率”。
- 不只展示单张成功样本；至少报告类别级统计和最差类别。

### P8：可复现交付

任务：

- 编写 README、环境文件、配置说明和运行命令。
- 提供小规模 smoke test 数据集或样本子集，保证不下载完整数据也能验证代码路径。
- 保存训练/评估配置、代码版本、随机种子、硬件信息和 checkpoint 元数据。
- 输出最终图表和结果表。

验收：

- 新环境按 README 可以重建前向模型、加载 checkpoint 并复现测试指标。
- 不依赖本机绝对路径。
- 关键实验有原始日志和可追溯配置。

## 5. 推荐关键路径

1. 冻结坐标、单位、归一化和探测区定义。
2. 完成角谱参考核并通过解析解和能量校核。
3. 完成前向 D2NN、探测器积分和逐样本归一化。
4. 完成有限差分梯度校核和小子集过拟合。
5. 完成零填充收敛和显存基准，确定最终 Npad 与 microbatch。
6. 执行 200 epoch 全量训练。
7. 评估、消融、图表和可复现交付。

前 5 步是硬门槛，不能跳过。尤其不能在全量训练失败后才回头检查 FFT 频率网格、坐标裁剪或梯度符号。

## 6. 主要风险与工程决策

### 风险 1：把“全连接”误解为任意权重

系统的层间算子由自由空间传播决定，只有相位面可训练，且耦合是平移不变的。工程文档和结果中应固定表述为“稠密平移不变耦合 + 逐层可训练相位”。

### 风险 2：零填充不足导致周期回绕

400×400 直接 FFT 不满足 10 mm 传播的采样条件。必须通过 Npad 收敛测试证明 2048 或更大网格足够，而不是只满足公式下界。

### 风险 3：全量训练算力不可控

2048×2048 complex128、5 层、batch=64 的中间场占用很高。第一阶段必须实测 micro-batch、梯度累积、checkpoint 和 FFT 时间，再决定训练资源。若无法承担 200 epoch，应缩小实验协议并明确这不是原方案的无损替代。

### 风险 4：预训练投影不保持性能

振幅+相位预训练可以提供 warm start，但投影到 a=1 的纯相位面后，实际系统已经改变。投影后的模型必须单独训练和评估。

### 风险 5：损失低不代表分类好

目标 `gk=Pin·δ_{k,c}` 要求全部输入能量进入正确探测区；有限孔径下通常存在非零损失下限。应以准确率为主，同时报告 η、对比度和区域外能量比例。

### 风险 6：坐标和方向错误会伪装成训练问题

MNIST 上采样、数组行方向、探测区左上角原点、y 向下以及 FFT shift 必须用可视化测试固定。任何半像素平移都可能造成难以解释的优化退化。

## 7. 建议的最小可执行里程碑

- M1：小网格能量守恒 + 高斯束解析对照通过。
- M2：400×400 单次传播和 5 层前向可重复运行，η 计算正确。
- M3：小网格有限差分梯度通过；完整网格解析梯度与 autograd 一致。
- M4：100 个样本过拟合通过，证明优化链路有效。
- M5：Npad 收敛和显存/时间基准完成，给出全量训练资源报告。
- M6：全量训练完成并输出准确率、η、混淆矩阵和相位/光强图。

只有 M1–M5 全部通过后，才建议启动 M6。
