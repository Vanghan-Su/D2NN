# 纯相位法工程调整

日期：2026-10-13

依据：`全连接光学神经网络-仿真方案v1-纯相位.docx`

## 1. 分支与模型

- Git 开发分支命名为 `纯相位法`。
- `TorchD2NN` 的默认模式仍为纯相位，不创建 `amplitude_logits`。
- 模型新增 `optimization_branch` 元数据：默认返回 `纯相位法`；仅在显式启用振幅优化时返回 `复振幅预训练`。
- 训练 checkpoint 写入 `optimization_branch`，便于区分正式纯相位结果和预训练结果。

## 2. 默认配置

- 默认计算网格从 4096 改为方案要求的 2048。
- `configs/base.json`、`src/d2nn/config.py`、`scripts/train.py` 和 `scripts/benchmark_forward.py` 保持一致。
- 默认层间距保持 5 mm，末层到探测面距离保持 10 mm。
- 默认振幅透过率保持 1.0，且训练入口默认关闭振幅优化。
- 训练入口默认有效批大小从 64 改为 16。
- 训练输出中的优化标记改为 `纯相位法`。
- 训练循环增加按 micro-batch 的进度日志，每轮保存 `history.json`，并额外保存验证损失最低的 `_best.pt` checkpoint。
- 相位/振幅绘图脚本根据 checkpoint 自动使用 `纯相位法` 或 `复振幅预训练` 的标题和文件名。

## 3. 复振幅预训练的处理

方案第 9 节允许“先复振幅预训练、再投影为纯相位、最后微调”。工程中保留该能力，但必须显式传入：

```text
--optimize-amplitude
```

该模式产生的输出标记为 `复振幅预训练`，不能作为最终纯相位器件结果。

## 4. 验证

- 21 项单元测试全部通过。
- `scripts/smoke_test.py` 通过，NumPy/PyTorch 前向一致，CUDA 路径可用。
- 使用 2048 网格完成 1 个纯相位训练批次。
- 检查 checkpoint 确认：
  - `optimization_branch = 纯相位法`；
  - `model_state_dict` 中不存在 `amplitude_logits`；
  - `simulation_config.padded_size = 2048`。
## 5. 1% 数据训练

- 数据：MNIST 训练集 600 张（总数 60000 的 1%），验证集 100 张（总数 10000 的 1%）。
- 训练参数：有效 batch size 32，micro-batch 8，20 epochs，学习率 1e-2，2048 网格。
- 最佳 checkpoint：epoch 20；验证损失 0.085315，验证准确率 54%，汇聚效率 0.294359。
- 总耗时：约 1599 秒。
- 输出目录：`outputs/20261013-095617_mnist_5mm_2048pad_纯相位法_random-init_600samples_20epochs`。
